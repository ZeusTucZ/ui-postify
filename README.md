# ui-postify

> **This repository is not a separate project.** It holds only a Vite +
> React + Tailwind starter template. The real Postify frontend lives in
> [ZeusTucZ/postify](https://github.com/ZeusTucZ/postify), under
> `ui-postify/`, together with the FastAPI backend in `server-postify/`.

Postify is a social posting app — posts with text and images, likes and
comments. See the [Postify README](https://github.com/ZeusTucZ/postify) for
what it does and how to run it.
